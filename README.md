# 印前检查-雪糕

Adobe Illustrator 的**印前检查面板**（CEP 扩展）。点一下就把文档里常见的印前问题
扫一遍，并把能在面板里直接做的动作（文字转曲、图片嵌入）一并做了。

当前版本：**v8.6** · 完整变更日志见 [README.txt](README.txt)

---

## 功能

点「开始检查」后，面板依次给出 **6 张检查卡**。六张卡**始终全部渲染**——没有问题也会
显示「无」，方便确认检查确实跑过。

每张卡的右上角都有状态徽标；有的卡会**并列第二个徽标**，用来单独表达另一类问题
（如卡①的「出血不足」、卡③的「缺字体 N」、卡⑥的「有叠印」）。

| 卡片 | 检查内容 |
| --- | --- |
| ① 画板 · 出血 · 色彩 | 画板尺寸；逐画板实测出血；色彩模式 |
| ② 隐藏对象 | 隐藏图层与隐藏对象 |
| ③ 字体转曲 | 未转曲文本框、字体清单、缺失字体、极小字号 |
| ④ 图片嵌入 | 嵌入 / 链接图片数量、未嵌入清单 |
| ⑤ 图片分辨率 | 低于 300ppi 的图片 |
| ⑥ 油墨 · 叠印 · 描边粗细 | 油墨总量、叠印、描边宽度 |

**清单类内容统一最多列 5 条**，超出时在标题行右端提示「仅列出前 5 处 / 5 张 / 5 个」。
扫描本身有配额上限（见每张卡的说明），配额提示会保留。

### 卡 ① 画板 · 出血 · 色彩

- **画板清单**：逐个画板列出名称与尺寸（`宽 × 高 mm`），当前画板标「(当前)」。
- **出血**：**逐画板实测**四条边（对象到画板边的实际距离，容差 0.05mm），不足 3mm 的
  画板会被列出，并标明**具体是哪条边**不足，如「上 0mm、下 0mm、右 2.9mm」；四边全判，
  未贴到边的方向按 0mm 计，空画板四边都按 0mm 报。全部达标时显示「出血全部 ≥ 3mm，达标。」
- **色彩模式**：常驻一行。CMYK 显示白字；RGB 显示红字并提示
  「请转 CMYK（文件 → 文档颜色模式）」。

徽标：主徽标 `CMYK`（绿）/ `RGB`（红）；出血不足时**追加**一个黄徽标「出血不足」。

### 卡 ② 隐藏对象

分别统计**隐藏图层**与**隐藏对象**，汇总为一行「隐藏图层 N 个 · 隐藏对象 N 个」，
并列出隐藏图层的名称（最多前 5 个）。没有隐藏内容时显示「无 隐藏图层 / 隐藏对象。」

徽标：`N 个`（红）/ `无`（绿）。扫描配额：前 3000 个对象。

### 卡 ③ 字体转曲

- **未转曲文本框**：列出总数与文档中用到的字体名（最多 8 种，超出折叠为「…等 N 种」；
  名字过长会单行截断，悬停可看全名）。
- **缺失字体**：命中时列出具体字体名，并追加一个红徽标「缺字体 N」。
  判定同时用三条判据：① 不在系统字体表中；② 系统字体表里是**占位条目**
  （无 style 且 family 为空或等于字体名）；③ **切分痕迹**——条目的 family / style 恰好是
  字体名在**首个连字符**处硬切出来的（style = 连字符后段，family = 前段 + 空格 + 后段）。
  ③ 是为「名字自带连字符的缺失字体」补的：这类字体旧版会整类漏报。
- **极小字号**：`N 处字号小于 6pt` 并列出样本（`文字 — N pt`）。**< 6pt 计数为黄，
  其中 < 5pt 的另补一行红字计数**；追加徽标「小字号 N」（有 < 5pt 时为红，否则为黄）。
- **隐藏文字**：树遍历只扫可见对象，隐藏文字单独统计，提示
  「另有 N 个隐藏文字未转曲，勾选"显示全部"可一并转曲。」（配额：前 500 个）
- **一键转曲**：有未转曲文本框（或隐藏文字）时出现按钮，配「显示全部」「解锁全部」
  两个勾选项，详见下文。

徽标：主徽标 `未转曲 N 个`（红，**可见 + 隐藏合并计数**）/ `已转曲`（绿）；
缺失字体与极小字号各占一个并列徽标。扫描配额：前 3000 个对象。

### 卡 ④ 图片嵌入

- **汇总行**：`嵌入图片: N 张 · 链接图片: N 张`，有链接源文件缺失时再补
  `· 缺失链接: N 张`。
- **未嵌入清单**：列文件名（最长 40 字符，悬停看**完整路径**）；源文件不存在的会
  标记「⚠ 源文件不存在」。
- **一键嵌入**：有链接图时出现按钮。确认框会提示
  **PDF / AI / EPS 矢量链接会按 300dpi 栅格化为位图（不再保留矢量）**。

徽标：`缺失 N 张` / `有链接图` / `全部嵌入`。扫描配额：前 3000 张。

> **口径提醒**：检查卡与清单**只统计可见对象**；而「一键嵌入」是**文档级操作**，
> 处理的是文档中**全部**链接图（含隐藏对象），确认框会写明总数。

### 卡 ⑤ 图片分辨率

- **汇总行**：`共 N 张图片 · 达标 N 张 · <300ppi N 张`。
- **清单**：文件名（截断，悬停看全名）+ 实际 ppi，最多 5 张。文档没有位图时显示
  「文档无位图。」
- ppi 用**未取整的原值**参与判定与排序（所以 299.75 不会被当成 300 放行），
  面板上显示时才取整。

徽标：`有 N 张偏低`（黄）/ `全部达标`（绿）。扫描配额：前 3000 张。

### 卡 ⑥ 油墨 · 叠印 · 描边粗细

按「问题类型」分块，固定顺序：

- **油墨总量 > 300**（红）——C+M+Y+K 超过 300 的对象
- **油墨总量 220~300**（黄）
- **色版 1~4%**（黄）——CMYK 某分量处于 0 与 5 之间（过浅分量单独标白）
- **叠印 N 处**（红）——处于叠印状态的对象；卡右上角并列红徽标「有叠印」
- **描边 < 0.1mm**（黄）——相同宽度合并显示，如 `0.09mm ×3`

每条样本前标 `[文字]` / `[图形]`；末尾灰字汇总正常数与 RGB / 专色 / 混合色。

> 叠印的读取口径：图形走对象级 `fillOverprint` / `strokeOverprint`，文字只能走**字符级**
> `characterAttributes.overprintFill` / `overprintStroke`。**所有叠印一律标红**——
> 包括「黑字压彩底」这类刻意的常规做法，所以有叠印不一定代表出错，请结合稿件判断。

## 一键转曲（两个选项）

- **显示全部**：转曲前显示隐藏图层，并取消对象级隐藏（Ctrl+3）
- **解锁全部**：转曲前解锁图层，并解除对象级锁定（Ctrl+2）与锁定组

| 勾选组合 | 效果 |
| --- | --- |
| 两项都勾 | 解除全部隐藏与锁定，转曲文档中所有文字 |
| 只勾解锁 | 转曲其中可见的文字；仍隐藏的文字跳过 |
| 只勾显示 | 转曲其中未锁定的文字 |
| 都不勾 | 只转曲本就可见且未锁定的文字，不改动任何状态 |

## 安装（Windows）

1. **关闭 Illustrator**
2. 双击 `安装.bat`
   —— 它会把扩展复制到 `%APPDATA%\Adobe\CEP\extensions\com.workbuddy.ai.preflight`，
   并写入 CEP 的未签名扩展调试开关（详见「已知限制」）
3. 重启 Illustrator → 菜单 `窗口 → 扩展功能 → 印前检查-雪糕`

卸载：双击 `卸载.bat`，再重启 Illustrator。
更新（仅替换文件）：双击 `更新.bat`，再重启 Illustrator。

### 双击没反应 / 装不上怎么办

按下面顺序排查（`安装.bat` 失败时也会在窗口末尾打印这几条）：

1. **先解压再运行**。不要直接在压缩包预览窗口里双击——那样 `%~dp0` 指向临时目录，
   复制必然失败。
2. **路径尽量避开中文和空格**。先整包挪到 `D:\ailight` 这类纯英文短路径再运行。
3. **解除文件锁定**：右键 `安装.bat` → 属性 → 勾选底部的「解除锁定」→ 确定，再双击。
   （从微信 / QQ / 邮件 / 网盘下载的 `.bat` 常被标记为"来自 Internet"而拦下）
4. **以管理员身份运行**：右键 → 「以管理员身份运行」。
5. **全手动兜底**（前四条都不行时）：把整个文件夹复制到
   `%APPDATA%\Adobe\CEP\extensions\com.workbuddy.ai.preflight`，
   然后在命令行执行下面这行打开调试开关，最后重启 Illustrator：

   ```
   for %V in (9 10 11 12 13 14) do reg add "HKCU\Software\Adobe\CSXS.%V" /v PlayerDebugMode /t REG_SZ /d 1 /f
   ```

   （若放在 `.bat` 文件里执行，`%V` 要写成 `%%V`）

## 环境要求

- Windows
- Adobe Illustrator 17.0 及以上（CC 2014+），CEP 9.0+
- 运行脚本需要 Illustrator 的 ExtendScript 环境（面板自带，无需另装）

## 已知限制

- Illustrator 脚本接口**读不到**文档「出血」的设置值，面板里的出血是**实测值**
  （对象到画板边的实际距离，容差 0.05mm）
- 一键转曲**不可撤销**，操作前建议先存盘
- 一键转曲**够不到符号（Symbol）内部的文字**：检查会把它计入「未转曲」，但转曲动作
  只遍历文档画布上的文本。若文档确实用到符号文字，报告里会提示符号个数
- 图形对象的叠印属性（`PathItem.fillOverprint` / `strokeOverprint`）**尚未在真机验证**：
  若属性名不成立，图形侧的叠印会**静默漏报**（不会崩溃、也不会误报）。文字侧走字符级
  `characterAttributes.overprintFill` / `overprintStroke`，已在 AI 28.0.0 验证可读
- 检查只统计**可见对象**（隐藏内容中的文字、图片会单列，不混进主计数）
- 本扩展**未签名**。`安装.bat` 会写入 `HKCU\Software\Adobe\CSXS.*\PlayerDebugMode`，
  这是 CEP 加载未签名扩展的**必要条件**，不是漏洞；不接受的话请不要安装
